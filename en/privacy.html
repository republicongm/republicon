Republicon Privacy Policy

Last updated: October 28, 2026

Republicon is an iPhone and iPad game that works without an internet connection. We do not collect, store or share personal data.

What Data Is Stored

Only your game progress: the president's name, party, flag and appearance, the state of the country, and your settings (sound, vibration, tips already viewed). All of it is stored locally on your device and is not sent anywhere.

Third Parties, Ads, Analytics

None. The game has no ads, analytics, tracking, accounts or in-app purchases.

Network: Exact Time Only

The only time the game goes online is to check the exact time. When you launch or return to the game, if an internet connection is available, the game sends an empty request (HEAD) to https://www.apple.com and takes only the current time from the response (the Date header). The request contains no save data, no name and no device identifiers, and no cookies are stored. This is needed to calculate fairly how long the game was closed if the phone was restarted. Without an internet connection, the game works as usual. Like any internet request, it is visible to the apple.com server (your device's IP address); we receive none of this.

Notifications

If you allow it, the game will remind you of deadlines (financial disclosure, deposit, election, club match). These are local notifications: the phone schedules them itself, and nothing is sent to any server. To turn them off, use the game's settings or your iPhone's settings.

Device Clock

To fairly credit income for the time the game was closed, the game compares the time you left and the time you returned using the device's system clock (after a phone restart, using the exact time from the network, see above). These timestamps are stored only in the save on your device.

Children

The game does not collect data about children or anyone else.

Deleting Your Data

Delete the app, and the save is deleted with it. Or in the game: Study → “Resign and Start Over.”
